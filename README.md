# PEC 2 · Visualización de Datos

Autor: Jesús Moreno Silvestre · UOC

Tres visualizaciones generadas en R Markdown. Los archivos HTML permiten consultarlas desde el navegador; los archivos Rmd contienen el código fuente.

- Histograma: histogram.html / histogram.Rmd
- Dendrograma circular: circular_dendogram.html / circular_dendogram.Rmd
- Horizon graph: horizon_graph.html / horizon_graph.Rmd

## Reproducir

En caso de querer reproducir cada visualización, se debe ejecutar cada Rmd en RStudio y usar Knit. Se necesitan los paquetes rmarkdown, palmerpenguins, ggplot2, scales, igraph, ggraph y latticeExtra. El dendrograma y el horizon graph descargan datos de Internet.

## Fuentes

- Palmer Penguins: https://allisonhorst.github.io/palmerpenguins/
- Eurostat/GISCO NUTS 2024: https://gisco-services.ec.europa.eu/distribution/v2/nuts/nuts-2024-files.html
- Copernicus / Our World in Data: https://ourworldindata.org/grapher/annual-temperature-anomalies

Los datos conservan las condiciones de reutilización de sus proveedores.
